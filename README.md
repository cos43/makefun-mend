mend is a command-line patch tool that applies AI-written edits in four formats — unified diff, SEARCH/REPLACE blocks, V4A and JSON edits — finding the lines each edit names at the first of three matching tiers and writing every change or none. It scores 1000/1000 on the competition's 100 public practice checks.

## Run it

```sh
node main.ts fix.patch
```
